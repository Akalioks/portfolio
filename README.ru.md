# Сайт-портфолио

Статический сайт. Весь текст вшит прямо в `index.html`, поэтому Google, превью ссылок (Telegram, LinkedIn, Upwork, Slack, X) и посетители со слабым интернетом видят страницу целиком, даже без JavaScript.

`index.html` собирается из `template.html` и `config.js` одной командой (нужен только Node.js, без установки пакетов):

```
node build.js
```

**Запускайте её после каждого изменения `config.js` или `template.html`**, иначе на сайте останется старый текст.

## Файлы

| Файл | Что внутри | Нужно править? |
|---|---|---|
| `config.js` | **Все тексты:** имя, контакты, услуги, цены, FAQ, 6 проектов, адрес сайта и описание для поиска | **Да, только его** |
| `template.html` | Структура страницы и мета-теги | Редко |
| `build.js` | Собирает `index.html` | Нет |
| `index.html` | Готовая страница (генерируется, руками не правьте) | Нет |
| `styles.css` | Дизайн, светлая и тёмная темы | По желанию |
| `app.js` | Только интерактив: фильтры, окно проекта, меню, тема | Нет |
| `og-image.png` | Картинка 1200×630 для превью ссылки | Пересоздайте, если поменяете имя или роль |
| `og/og-image.html` | Исходник этой картинки | Вместе с ней |
| `Aleks-Kalikas-Resume.pdf` | Резюме, ссылка на него есть на сайте | Пересохраните из Word, если обновите резюме |
| `resume/Aleks Kalikas.docx` | Исходник резюме | Да, при изменениях |
| `img/` | Ваше фото `aleks.webp` (квадрат, 640×640) и скриншоты проектов | Да, при замене фото |

## Превью ссылки (og-image.png)

Поменяйте текст в `og/og-image.html` и пересоздайте картинку через Edge:

```
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=1200,630 --virtual-time-budget=5000 --screenshot="$PWD\og-image.png" "$PWD\og\og-image.html"
```

Проверить, как выглядит превью: [opengraph.xyz](https://www.opengraph.xyz/) или отправьте ссылку себе в Telegram. Telegram кэширует превью: чтобы обновить, отправьте ссылку боту @WebpageBot.

## Что заменить в первую очередь (`config.js`)

1. `name`, `initials`: ваше имя и инициалы для логотипа.
2. `contacts`: ваш Telegram, почта, а позже ссылки на Upwork, Fiverr и GitHub. Пустая ссылка означает, что кнопка не показывается.
3. `languages`: языки, на которых вы работаете.
4. `packages`: цены. Сейчас там стартовые ориентиры, поменяйте их под себя.

## Как заполнить проект, когда он готов

Найдите проект по `id` в массиве `projects` и поменяйте поля:

```js
status: "live",                        // вместо "soon": метка станет «Live demo»
links: {
  demo:   "https://t.me/bookme_demo_bot", // живой бот или сайт
  video:  "https://www.loom.com/share/...",
  github: "https://github.com/you/bookme"
},
cover: "img/bookme.png",               // скриншот вместо рисованного макета (по желанию)
result: "..."                          // только реальные цифры, иначе оставьте ""
```

Тексты `problem`, `solution` и `stack` уже написаны под задуманные проекты. Если реализация получится другой, поправьте их, чтобы описание совпадало с тем, что вы сделали.

## Как выложить в интернет (бесплатно)

Перед выкладкой запустите `node build.js`. На сервер нужны: `index.html`, `styles.css`, `app.js`, `og-image.png`, `Aleks-Kalikas-Resume.pdf` и папка `img/` (в ней фото). `config.js` браузеру больше не нужен.

**Вариант A: Netlify Drop (проще всего).** Откройте app.netlify.com/drop и перетащите туда папку `portfolio`. Через минуту появится ссылка.

**Вариант B: GitHub Pages.** Создайте репозиторий, загрузите в него файлы и включите Settings → Pages.

**Вариант C: Vercel.** Подключите репозиторий с GitHub.

Позже можно купить домен (примерно €10 в год), например `yourname.dev`, и привязать его к сайту.
